## Stakeholder reality

- [2026-05-21] **Solo development**. Branch / PR rituals exist to
  enforce discipline (golden tests, CHANGELOG, ADR numbering), not
  because there are reviewers. Treat `make test && make lint` as the
  binding gate.
- [2026-05-21] **Dogfooding milestone** (ROADMAP "Dogfooding") is the
  long-term north star: the aikata repo should eventually be
  reproducible by `aikata init --preset standard --oss --ai-tools
  claude,cursor`. Don't optimize a feature that pulls the repo away
  from that reproducibility unless an ADR justifies it.
